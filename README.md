# Audio Material Classifier (Сервис определения материала по звуку удара)

Данный сервис предназначен для автоматического распознавания материала объекта (например, металл, дерево, пластик, стекло и т.д.) по аудиозаписи звука удара по нему. Проект разработан в рамках хакатона и развёрнут на сервере.

## Основные возможности

### Базовый функционал

* **Загрузка и обработка аудио:** Поддержка форматов WAV и MP3.

* **Единый пайплайн предобработки:**

  * Конвертация в моно-режим.

  * Ресемплинг до $16\,000$ Гц.

  * Фильтрация низкочастотных шумов (High-Pass Butterworth filter, cutoff = $100$ Гц).

  * Нормализация длительности (приведение к $5.0$ секундам с помощью обрезки или дополнения нулями).

  * Извлечение признаков: $13$ MFCC (Mel-Frequency Cepstral Coefficients).

* **Классификатор:** ML-пайплайн на базе Support Vector Classifier (`SVC` с RBF-ядром), калиброванный через `CalibratedClassifierCV` для получения точной оценки уверенности (probabilities).

* **Оценка качества:** Автоматическое разделение выборки на обучающую и тестовую ($80/20$, стратифицированное), с выводом Confusion Matrix и Classification Report.

### Дополнительные фичи (Advanced Options)

* **Запись с микрофона:** Прямая запись аудио из браузера с моментальной отправкой на инференс.

* **Визуализация спектрограммы:** Вывод спектрограмм и частотных характеристик загруженного сигнала во фронтенде.

* **Детекция шума и отклонение плохих записей:** Вычисление среднеквадратичного значения (RMS) сигнала. Если запись слишком тихая или содержит только фоновый шум ($RMS < 0.005$), сервер возвращает ошибку `400 Bad Request`.

* **Логирование и БД:** Сохранение истории посещений (`VisitLog`) и всех произведенных предсказаний (`PredictionLog`) в СУБД PostgreSQL.

## Технологический стек

* **Backend:** Python 3.14+, FastAPI, SQLAlchemy, PostgreSQL, PyTorch / Torchaudio, Librosa, Scikit-learn, NumPy, SciPy.

* **Frontend:** React, Vite, Tailwind CSS, Web Audio API / HTML5 Recording API.

* **Testing:** Unittest.

## Установка и запуск

### 1. Требования

* Python 3.10+

* Node.js 18+

* Запущенный экземпляр PostgreSQL

### 2. Настройка Backend

1. Склонируйте репозиторий и перейдите в корень проекта:

   ```bash
   git clone <repository_url>
   cd <repository_folder>
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Установите зависимости Python:

   ```bash
   pip install -r requirements.txt
   ```

4. Установите переменную окружения для подключения к PostgreSQL (или оставьте значение по умолчанию):

   ```bash
   export DATABASE_URL="postgresql://postgres:postgres@localhost:5432/hackaton"
   ```

5. (Опционально) Обучите модель на имеющихся данных:

   ```bash
   python -m app.train
   ```

6. Запустите FastAPI сервер:

   ```bash
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

### 3. Настройка Frontend

1. Перейдите в директорию `frontend`:

   ```bash
   cd frontend
   ```

2. Установите Node-зависимости:

   ```bash
   npm install
   ```

3. Запустите приложение в режиме разработки:

   ```bash
   npm run dev
   ```

## Тестирование

Для запуска тестов предобработки аудио и извлечения признаков выполните:

```bash
python -m unittest app/audio_utils.py
```

## Ограничения модели и возможные улучшения

1. **Зависимость от предмета, которым совершается удар:** Разные предметы-ударники (металлическая ложка vs деревянный палец) дают разный спектральный отклик.

2. **Длина записи:** Оптимизировано под короткие импульсные звуки (удары до 5 секунд).

3. **Фоновый шум:** Высокий уровень постороннего шума или гула отсекается по порогу RMS ($0.005$), однако при близких значениях спектральные характеристики могут искажаться.
